# Sunday 22 November 2026 — The World in One Day

An entry for make.fun's daily news-image bounty: one front-page image that
sums up Sunday 22 November 2026 world news — 36 dated stories across 7
regions, an atlas map with red dots marking story places, illustrated
cards for the day's biggest stories (COP31 collapse in Antalya, the
186-drone night over Ukraine, Bahrain and Hormuz strikes, Sunday sport),
a by-the-numbers strip, voices of the day, and a sports wire.

The program at `main.py` copies the bundled `entry.png` to
`/output/entry.png` byte-for-byte. Standard library only, deterministic,
no network.
